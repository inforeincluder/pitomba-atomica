# Portfólio — PITOMBA ATÔMICA LAB

Primeira versão de site editorial estático, responsivo e sem dependências de build.

## Arquivos
- `index.html`: conteúdo e estrutura.
- `assets/css/style.css`: identidade visual e responsividade.

## Publicação no GitHub Pages
1. Abrir Settings do repositório.
2. Entrar em Pages.
3. Em Build and deployment, selecionar Deploy from a branch.
4. Selecionar branch `main` e pasta `/ (root)`.
5. Salvar e aguardar a publicação.

URL esperada: https://inforeincluder.github.io/pitomba-atomica/

## Estado desta versão
